# Regras do Projeto RESHT Gourmet

1. **Atualização de Documentos Obrigatória**:
   Sempre que fizer qualquer modificação no código (HTML, CSS, JS), atualize obrigatoriamente:
   - `DOCUMENTACAO.md`
   - `PASSOS.md` (marcando `[x]` nos itens concluídos)
   - `CONTEXTO.md`

2. **Fluxo por Passos (PASSOS.md)**:
   - Siga a ordem de prioridade definida em `PASSOS.md`.
   - Só avance para o próximo passo quando o usuário solicitar expressamente.

3. **Texto para Commit**:
   - Ao concluir qualquer alteração ou resposta, forneça sempre uma mensagem de commit clara no padrão Conventional Commits (ex: `feat: adicionar gestão de usuários no painel admin`).
